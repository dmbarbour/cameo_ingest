# ADR-0005: The deterministic text is the authority; generated text is labelled

- **Status:** Accepted, 2026-09-29.
- **Sources:**
  - BASE-025R1;
  - FU-008;
  - AR-012R3;
  - `docs/design/architecture.md`.

## Context

An LLM can invent structure, and a reader of the output, or a retriever, can't tell invented text
from the model's own. The layout and the model already state every element, relationship and
shape exactly.

## Decision

- **The model's facts are written deterministically:**
  - pages, tables and the index;
  - each diagram's numbered legend and connection list.
- **LLM text adds meaning only, never facts the text lacks.** Each prompt gets the deterministic
  text and is asked to explain it (ADR-0011).
- **Every generated chunk is labelled:**
  - its kind is `generated:*`;
  - its text says "(generated by <model>; not part of the source model)", from one
    `provenance.generated_by`;
  - it carries its model and template version.
- **A tree without the LLM is complete.** Generated text is optional (`--no-llm`).

## Consequences

- **Errors are confined:** a weak or mistaken description can mislead, but never removes a fact.
  Validation measures what a model reads from the images (ADR-0016).
- **Tests enforce the labels** on every sample run.
